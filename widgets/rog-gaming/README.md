# ROG Gaming HUD v0.9
The power-profile selector now uses a frameless, separate Qt Quick Window.
The custom glass border, close button, Escape shortcut, scrolling, profile indicators and launch action remain.
The Gaming HUD does not resize when the dialog opens.
Install with `bash install.sh`, then restart plasma-plasmashell.service.
Not tested live in KDE Plasma; Wayland compositors may manage positioning and focus differently.
